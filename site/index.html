02 / METHOD

Small loop. Hard signal.

Every score comes from executable behavior,
not another model’s opinion.

01

Prompt

The model sees a start buffer, target buffer, natural-language instruction, and keystroke notation.

02

Replay

Its answer is translated to bytes and replayed in clean, headless Vim with shell access disabled.

03

Compare

The saved buffer is compared byte-for-byte with the target. Correct answers are scored for keystroke efficiency.

model output→keystroke bytes→vim -u NONE→exact diff
